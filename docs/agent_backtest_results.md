## 模型找到的候选

名称：`VolPriceDivergence`。

```text
rank(ts_mean(volume,5) / (ts_std(close,5) + 0.001))
```

模型假设：放量滞涨可能随后补涨。表达式实际为成交量均值除以价格标准差，没有明确表达“滞涨”的方向；原始股数及价格水平跨股票不可比，容易形成规模/股价偏好。没有在看到结果后改公式或反转信号。
