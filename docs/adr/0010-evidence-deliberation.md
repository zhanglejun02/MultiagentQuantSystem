# ADR-0010: 以证据协议组织独立研究与有限审议

- 状态：Accepted
- 日期：2026-10-16

## 背景

原黄金研究按 Researcher → Critic → Statistician → Orchestrator 串行传递观点。
后续角色容易围绕第一个故事展开审查；批判没有作者修订环节，最终建议也缺少独立发布门禁。
扩大角色数量不能补齐宏观数据，也不能替代本地统计、回测和晋级校验。

## 决策

1. 保留 Research Plane 隔离，不引入新的编排框架或交易工具。
2. 黄金先运行固定参数的确定性诊断，冻结同一份证据包；技术、宏观、量化、风险首轮互盲。
   只有具备证据的角色调用模型。宏观缺失由本地明确弃权，不让模型补写故事。
3. `EvidencePackage` 是事实唯一来源；`ResearchState` 只引用ID，短观点与原始对话分离。
   本地校验ID、空值、角色身份及修订置信度；引用有效并不证明自然语言蕴含，仍需终审。
4. 本地规则仅选择最大分歧，相关双方各一次交叉质询与作者修订。证据包不变时不得提高置信度。
   不追求无限辩论或强行共识，允许撤回、证据不足、未解决和预算跳过。
5. 统筹仅汇总最终结构化观点。终审员使用不同模型、隔离上下文，只审草案与事实；
   `PASS` 才发布，`REVISE` 最多一次修订复审，`REJECT/UNAVAILABLE` 不发布建议而保留研究。
6. 因子仍保留固定DSL候选和四角色契约；先本地计算，再让两个审查者并行独立评估。
   不把黄金配置协议机械套到因子发现，不改变 Factor/Strategy Promotion。
7. 所有请求预留预算，原始请求/响应及初始观点/修订/hash归档。旧不可变报告不重写、不自动补调用。

## 取舍与约束

- 固定MA20/60、波动率目标12%、滚动止损8%，消除先由模型选参数再解释同样本的循环；
  这不是调参后的最优规则，只是可复核的研究基准。
- 目前没有宏观序列与独立样本外，因此明确证据不足，仅允许等待意见，不能据上涨价格自动建议配置。
- 六个黄金逻辑角色不等于六次固定调用；通常5次，最多9次有效调用，硬上限12次/64000 tokens含格式修复。
- 同一家模型可以承担不同上下文的分析与终审；终审至少不同于统筹模型。上下文隔离不等于模型误差独立。
- 证据补充需新快照。自动宏观采集、任意专家路由和置信度校准后续实现，不在本次宣称范围。
