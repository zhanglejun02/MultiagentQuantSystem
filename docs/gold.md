# 黄金观察与配置

入口 `/gold`。人民币 Au99.99 现货既是观察基准，也是默认研究对象；另可选择四只实物黄金 ETF。
AU 期货读取既有市场流水线；宏观已有独立采集/研究模块，黄金通过注入 reader 消费指定冻结事实。
官方查询链接本身不算证据。页面包含行情、独立手工配置、
独立多视角审议、终审后的建议和可检查的策略规则，不下单，不把回测持仓或期货保证金当成个人黄金资产。

## 同步与启动

仓库根目录执行，不需要 Tushare Token 或模型账号：

```bash
.venv/bin/python scripts/sync_gold.py
.venv/bin/python scripts/sync_gold.py --as-of 2026-10-14
```

CLI 与网页研究共用 `GoldService.refresh`，每次调用都重新请求源站，不把缓存读取称为采集。
上海时区18:00之前最多纳入昨天，18:00之后可纳入当天；这是保守的完成日线上限，
不保证源站在此时已发布。窗口为截止日前730个自然日；
接口覆盖可能更短，页面展示实际区间。“全部”指当前快照，不是上市以来。
首次采集遇到2017年官方历史OHLC异常，未修造坏值；观察窗口内仍严格拒绝异常数据。

CLI 与 Dashboard 使用同一数据库及 Artifact 根目录，默认 `var/quant.db` 和 `var/artifacts`，
可用 `QUANT_DB_URL`、`QUANT_ARTIFACTS_ROOT` 覆盖。API 全局默认 PostgreSQL，使用 SQLite 时显式指定：

```bash
set -a && source .env && set +a
QUANT_DB_URL="sqlite:///$PWD/var/quant.db" \
  .venv/bin/python -m uvicorn quant_system.api.app:factory --factory --host 127.0.0.1 --port 8000 --workers 1
```

另一个终端：

```bash
cd web/dashboard
npm run dev
```

访问 http://127.0.0.1:5173/gold 。页头刷新只读本地快照；“刷新数据并分析”重新采集并调用模型。
仅看行情不需要加载 `.env`；启用研究时使用既有 Kimi / DeepSeek 凭据和角色路由，模型 API 可能收费。
可用 macOS launchd 定时执行同步命令；本版本没有安装系统级定时任务。

## 每轮分析与策略

1. 选择 Au99.99 现货或黄金 ETF、研究仓位上限和重点。研究上限最多为总资产30%，不是推荐比例，也不修改手工配置。
2. `gold.collect` 重新采集现货及四只 ETF 日线并冻结，`gold.research` 消费指定 `snapshot_id`。联合任务可另给 `macro_snapshot_id`，所有采集完成后统一冻结知识截止；研究不随“最新快照”漂移。
3. 本地先计算固定MA20/60、12%波动率目标、8%滚动止损的价格指标、诊断与成本压力，形成带ID/定义/来源的单份证据包；模型不选择或重算参数。
4. 技术、量化、风险首轮并行独立形成结构化观点，互不见他人的结果。宏观事实只能经 reader 校验注入，不直接 import 宏观服务或读取宏观模型意见；不足时本地弃权、置信度0，不调用模型补故事。
5. 本地检测最大分歧，只向相关双方发一次交叉质询与作者修订。原始/修订观点、证据请求及置信度变化保留；无新增证据不能提高置信度。
6. 统筹读取最终观点及分歧，生成报告与3至12个月建议草案；不同模型的独立终审只见事实和草案，不见前面讨论。
7. 仅终审PASS发布建议。REVISE允许一次作者修订再复审，REJECT、不可用或预算不足则建议为空，研究仍归档，不显示未审草案或冒充等待。
8. 本地门禁决定报告结论，模型不能覆盖。无独立样本外，结果固定 `OBSERVE`，始终 `deployment_eligible=false`。

策略族仍为双均线趋势、20观测波动率缩仓和滚动最高收盘价止损。V4使用上述固定默认参数，
不由模型在允许窗口内搜索候选；历史报告保留各自原参数。报告展示进入、退出、仓位、执行和失效条件，以及对应参考价，
不是只有模型文字。规则信号表示研究状态，不构成个人账户的买卖指令。

历史诊断仅使用前一观测及此前的价格产生信号，下一观测开盘执行；每5个观测调仓，退出优先。
使用连续份额、零现金利息、未复权价格和单边10bp / 20bp成本假设，不含分红、最小交易单位与流动性约束。
现货按连续克数构造无杠杆金价参考组合，元/克；不代表银行积存金或金条可成交价，
也未计银行价差、保管、提取与回购费用。ETF按元/份展示。现货研究不要求ETF接口成功，
但手工资产记录仍只支持ETF，不会把参考金价直接当成个人实物持仓。
收益以初始总资产为分母，买入持有按相同初始仓位持有且未扣费。这是全样本诊断，
不是独立样本外、事件驱动权威回测或收益预测。

宏观弃权时通常5次有效调用：3位分析师、统筹与终审；若宏观证据充分并调用该视角则增加调用。
最大分歧双方修订最多增加2次，建议修订复审最多再增加2次。
黄金任务上限12次、64000 tokens，同时受共享根剩余预算及更低配置约束。
每次结构化响应最多一次格式修复，也计预算；根、子任务、planner 结转与终审共用账本，
并发前锁内预留，未知 usage 保守记账。受管传输无隐式重试，不承诺美元费用硬上限。
缺本任务凭据禁用研究，不要求无关模块全部就绪。所选 ETF 或现货采集失败、沿用旧报价、超过4个自然日、历史不足或与现货基准最新日期不一致时，不调用模型。
宏观来源能力已接入，不表示关键证据已齐；新闻、仓位、全球资金流、NAV/IOPV仍未覆盖，
模型不得将链接或子任务意见冒充本轮新事实。

### 中长期建议口径

统筹者输出 `investment_advice` 草案，终审PASS后才成为公开字段。协议支持等待、条件式分批配置或防守观察，
与候选策略是否可晋级分开。摘要上限140字符、每条依据上限65字符、复核条件上限100字符；
提示模型保持更短，页面将这部分放在研究报告末尾。

本地计算Au99.99近126/252观测收益、相对MA120/MA250位置和距近252观测高点回撤，
另提供策略诊断收益差、双倍成本与独立样本外状态。模型只能引用已存在的证据键，至少含一条中长期金价事实，
展示数值由本地绑定，不由模型填写。缺少长期历史、存在弃权或关键分歧未解决时只允许等待。
未来证据充分时仍需半年与一年收益、两条长期均线位置均为正、距近一年高点回撤小于15%，才可能允许条件式分批配置。
接入首批宏观事实不等于消除全部缺口，V4不会仅凭价格上涨或单个宏观值发布分批配置。
这是保守证据约束，不是已验证的择时规则。

建议统一低置信度：价格趋势不证明未来收益，宏观覆盖仍有缺口，也不知道个人全部资产与风险承受能力；
不输出保证收益、杠杆或银行实物成交承诺。建议与报告同快照归档，不因刷新而改变。
升级前未含建议的不可变报告显示“该历史报告未生成中长期建议”；已有建议但没有终审的旧报告明确标记“历史建议 · 未经独立终审”。
不临时补造观点、审计或额外调用。`advice_audit.rounds`采用1起始轮次，发布哈希绑定实际PASS版本。

任务接口：`GET /api/gold/research/status`、`GET/POST /api/gold/research/runs`、
`GET /api/gold/research/runs/{run_id}`。提交返回202，页面每2秒查询实际阶段；不自动重新提交失败分析。
`GoldResearchService` 是共享 Runtime 的兼容 facade：单机单 API worker 同时一个根任务，
与公共黄金/宏观/因子任务共用活动槽，不重复 dispatch 或另建调用账本。
最多两个子任务并行、根模型并发最多三个；冲突返回409。
启动将通用未完成运行记为 `INTERRUPTED`、未结束调用为 `UNKNOWN`，旧黄金 DTO 投影为失败，
不自动续跑或重发请求。取消为协作式，进行中的调用退出前不释放槽。
不支持多 worker、多机队列或公网部署。历史展示最近20条，旧产物不删除；未保存配置不会被后台刷新覆盖。

新阶段与调用统一写入 `research/runtime` 的 `RESEARCH_RUN/EVENT/CALL/PLAN`，
最终领域报告继续在 `gold/research/reports` 注册为 `GOLD_RESEARCH_REPORT`。
旧 `gold/research/runs` 的 `GOLD_RESEARCH_RUN` 仅历史兼容读取；写入旧档恢复必须显式
`recover_legacy()`，普通 GET 不做恢复写入。不双写两套运行状态，不覆盖旧 Artifact。
报告协议为 `gold-deliberation-v4`，共享审议协议为 `evidence-deliberation-v1`。
报告保留请求、模型路由、原始 messages / response、请求标识、tokens、参数和门禁，
以及 `evidence_package/deliberation/advice_audit`。首轮、最终观点与修订分开，不传长聊天记录给后续角色；
血缘和证据清单绑定本轮黄金快照及可选宏观快照，`data_snapshot_id` 只指底层原始
`DATA_SNAPSHOT`；原始调用通过通用收据归档，不在每次运行 revision 复制整段原文，不保存密钥。

公共 `/research` 展示模块、计划、任务树、事件、根预算、收据、取消与历史；`/gold` 专属行情和报告保留。
根计划只汇总模块摘要与批准 hash，不新增投资建议模型门禁，不能重新发布被拒绝建议。
架构与取舍见 [research_modules.md](research_modules.md)、[multi_agent_llm.md](multi_agent_llm.md)
和 [ADR-0011](adr/0011-modular-research-runtime.md)；[ADR-0010](adr/0010-evidence-deliberation.md) 保留历史决策。

## 数据与质量

| 数据 | 来源 | 口径 |
| --- | --- | --- |
| Au99.99 | 上海黄金交易所 `/graph/Dailyhq` | 元/克，日OHLC，非SHAU早午盘价 |
| 518880、518800、159934、159937 | 腾讯证券公开日线 | 元/份，未复权，不含分红 |
| AU 主力 | 既有 `MARKET_SNAPSHOT` | 缺失显示未接入，不构造连续合约 |
| 可选冻结宏观事实 | FRED + SAFE，经独立宏观模块 | DGS10/DFII10、广义美元 DTWEXBGS、纽约午间 DEXCHUS、中国黄金储备数量及美元估值；只读指定快照 |
| 规则与补充查询 | 外汇局、中国货币网、交易所 | 官方链接不是已采集事实 |

- 公开查询不等于稳定免费API授权；遵守网站条款，不绕过访问限制。
- 序列非空、日期唯一递增、价格正且有限、OHLC自洽；窗口内异常阻止该品种发布。
- 现货失败不发布新快照；ETF失败显式告警，可沿用旧报价，保留原行情日期、抓取时间和 `retained_symbols` 标识。
  沿用报价只供展示；所选ETF若沿用旧价，新研究失败，不用旧价冒充本轮证据。
- 原始响应在 `gold/raw`、行情在 `gold/snapshots`、配置在 `gold/allocations`，均内容寻址并注册。
  行情引用原始数据，沿用报价时也引用旧快照；读取核验内容hash。
- 超过4个自然日标陈旧，未接交易所日历，长假可能误报。
- 接口没有逐日首次发布时间；抓取时间不是历史 `available_at`。仅用于观察，不是已认证PIT回测数据。
- 成交量/成交额未核定单位，暂留空；未接NAV/IOPV，不计算实时折溢价或资金净流入。

FRED 可选免费 key，当前可用性/线上采集未验证；SAFE 仅源站 HTML 样本读取不能代表完整生产宏观报告。
宏观历史值以实际抓取时间保守可用，不自动认证 ALFRED/PIT 历史；中国储备不是全球央行需求，
估值变化不是买入量。精确来源与单位见 [macro.md](macro.md)。

## 图表与配置

- K线、区间收益、回撤可切换；比较严格取共同日期并同日起归一化，不前向填充。
- 收益为未复权收盘价收益；回撤以所选窗口内收盘高点计算。
- 波动率为对数收益样本标准差乘 `sqrt(252)`，仅是观察统计。
- 配置独立手工维护，数量为份、成本为元/份；其他资产必须排除黄金。
  黄金占比 = 黄金ETF市值 /（黄金ETF市值 + 其他资产）。目标比例是用户填写值，不是建议。
- 缺报价时总估值与比例未知，不按零计；旧报价估值明确显示日期及陈旧提示。
  未录入不生成持仓；不自动读取券商，不包含金条、积存金或期货敞口。
- 每次变更保存新版本及血缘，刷新后仍存在。本地单用户使用，无多人冲突处理；勿暴露到公网。
